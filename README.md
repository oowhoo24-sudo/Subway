# 🚇 부산 지하철 이용객수 지도 분석 앱 (Busan Subway Analysis)

Streamlit과 Folium을 활용하여 부산 지하철 역별 이용객 데이터를 시각화하는 파이프라인 웹 애플리케이션입니다. 비전공자 및 파이썬 초보자도 쉽게 사용할 수 있도록 직관적인 인터페이스로 구성되어 있습니다.

---

## 📌 주요 기능
1. **CSV 파일 업로드:** 부산 지하철 데이터(`busan_subway.csv`) 업로드 및 데이터 테이블 시각화
2. **호선별 필터링:** 멀티셀렉트(`multiselect`)를 이용해 원하는 호선만 선택하여 조회
3. **이용객 상위 5개 역 추출:** 필터링된 데이터 중 가장 이용객이 많은 상위 5개 역을 표로 제공
4. **인터랙티브 지도 시각화 (`Folium`):**
   - 호선별 고유 색상 적용 (1호선: 주황, 2호선: 초록, 3호선: 갈색, 4호선: 파랑)
   - 이용객 수의 제곱근에 비례하는 원(`CircleMarker`) 크기 설정으로 시각적 직관성 강화
   - 마우스 오버 시 역명 표시, 클릭 시 상세 이용객 수 팝업 제공

---

## 🛠️ 사용 기술 스택
* **Python**
* **Streamlit** (웹 인터페이스 구현)
* **Pandas** (데이터 전처리 및 분석)
* **Folium & Streamlit-Folium** (인터랙티브 지도 시각화)
