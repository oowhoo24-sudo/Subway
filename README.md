# 🚇 부산 지하철 역별 이용객 수 지도 분석 앱 (Streamlit & Folium)

Streamlit과 Folium을 활용하여 부산 지하철 역별 이용객 수를 지도 위에 시각화하는 웹 애플리케이션입니다.

---

## 📌 주요 기능

1. **CSV 데이터 업로드**: `busan_subway.csv` 파일을 웹 화면에서 직접 업로드하여 지도 및 데이터를 생성합니다.
2. **호선 필터링 (Multiselect)**: 원하는 호선(1호선, 2호선, 3호선, 4호선 등)을 선택하여 해당 호선의 역만 지도와 표에 출력합니다.
3. **호선별 색상 구분 마커**:
   - 🧡 **1호선**: 주황색 (`orange`)
   - 💚 **2호선**: 초록색 (`green`)
   - 🤎 **3호선**: 갈색 (`brown`)
   - 💙 **4호선**: 파란색 (`blue`)
4. **이용객 수 비례 원형 마커 (CircleMarker)**: 이용객 수의 제곱근($\sqrt{\text{이용객수}}$)에 비례하는 반지름으로 지도에 표시합니다.
5. **인터랙티브 정보 제공**:
   - **마우스 호버 (Tooltip)**: 역명 및 호선 확인
   - **클릭 (Popup)**: 해당 역의 총 이용객 수 확인
6. **이용객 상위 5개 역 표 출력**: 선택한 호선 기준 이용객 수가 가장 많은 상위 5개 역을 정렬하여 표로 보여줍니다.

---

## 📂 데이터 형식 (`busan_subway.csv`)

업로드하는 CSV 파일은 총 **112개 역** 정보와 함께 아래의 열(Column) 이름을 정확히 포함해야 합니다.

| 열 이름 (Column) | 데이터 타입 | 설명 | 예시 |
|---|---|---|---|
| **호선** | 문자열 (String) | 지하철 노선 이름 | `1호선`, `2호선` |
| **역명** | 문자열 (String) | 지하철 역 이름 | `서면`, `해운대` |
| **위도** | 실수 (Float) | 역 위치 위도 좌표 (WGS84) | `35.157708` |
| **경도** | 실수 (Float) | 역 위치 경도 좌표 (WGS84) | `129.059127` |
| **이용객수** | 정수 (Integer) | 일일/월간 이용객 수 | `45230` |
